# RK Creation Surat — Luxury Ethnic & Silk Couture Website

Official web application and digital luxury catalog for **RK Creation**, Surat's premier manufacturer and wholesaler of Navratri Chaniya Choli, Royal Velvet Bridal Lehengas, Patola & Bandhani Sarees, and Banarasi Katan Silk.

## ✨ Features
- 🪘 **Authentic Navratri & Bridal Showcase**: High-resolution catalogs for Kutchi mirror-work Chaniya Choli, Patola, Bandhani, and Bridal Couture.
- 📸 **Instagram Lookbook Integration**: Live feed showcasing posts and reels from official client profile `@rk_creation_surat_gj5`.
- 🎙️ **Voice-Powered Search**: Real-time voice speech recognition for fast hands-free product searching.
- 📱 **Mobile-First & App-Style Experience**: High-density 2-column mobile catalog with sticky mobile bottom navigation.
- 👑 **B2B Wholesale & Reseller Portal**: 1-click toggle between retail single-piece rates and factory wholesale set pricing.
- 💬 **1-Click WhatsApp Quotation Generator**: Instant order routing to Surat showroom concierge with pre-formatted product SKUs, shades, and quantities.
- 📹 **Live Video Consultation Booking**: Integrated showroom video slot reservation for NRI and Pan-India buyers.
- 🌍 **Multi-Currency Support**: Instant price conversions for INR (₹), USD ($), AED, GBP (£), CAD, and EUR (€).

## 🚀 Tech Stack
- **Frontend**: React 18, Vite 6
- **Styling**: Tailwind CSS v3, PostCSS, Custom Vanilla CSS Design System
- **Icons**: Lucide React
- **Animations**: Canvas Confetti, CSS Keyframe Glows & Shimmers

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
